{% load i18n %} {% comment %} "Details" of the book page (books/book_detail.html): the edition. Inside the cached fragment book_detail_body: the book's own fields, the publisher's name and the formats on sale; all of them drop the cache when saved (books/signals.py). Only the known values: a book added before these fields may have none. The cover and the pages belong to a format (BookFormat): the cover of the paper one, the pages of the paper one or else of the e-book. get_..._display: the label of the choice in the current language ("Тверда", not "hard"). A value with a filter of the catalog is a chip like the categories: a click opens the catalog with that filter set (the same GET parameters as the filter panel, books/filters.py). The pages have no filter: text. {% endcomment %}
